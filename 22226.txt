Advantages of Virtualization
----------------------------

Main advantages of virtulization 
1) Less time troubleshooting hardware related issues
2) Frees up budget to allocate it toward other important procurements
3) Gives IT support more ability to see things remotely 
4) Ability to use more than one OS on 1 computer than purchasing another one
5) Fast ability to spin up VMs
6) Ability to run servers in a more cost-effective manner on a continuous basis
7) Ability to run custom software virtually without having to install it manually on hardware

1st advantage:
Ease and speed
Spin up new resources
And tear them down

Agility 
Stand up a virtual machine in a matter of minutes to test whether you like the OS or not

Cost savings

3rd advantage:
Easy of backups good for disaster and recovery

We can create snapshots to revert back to various states in a VM

Mission critical server is virtualized
Create a snapshot of a known working point before the update
Beneficial for hardware failure

Move virtualization off premises just putting it in the cloud - so no need to maintain or replace
